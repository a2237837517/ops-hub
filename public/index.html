还没有客户端

下载 Agent 安装包，装到 Windows 或 Linux 机器后会自动上线。

也可以从顶部「下载客户端」进入下载页。

下载客户端

选择目标系统下载安装包，然后按下面的步骤安装。安装包由本机 Hub 直接提供。

🪟 Windows

Windows Server 2008 R2 / 2012 / 2016 / 2019 / 2022，Windows 10/11

Windows x64 Windows x86
🐧 Linux

主流 x86_64 / arm64 发行版（CentOS、Ubuntu、Debian、Rocky 等）

Linux x64 Linux arm64 Linux x86

安装步骤

  1. 下载对应系统的安装包，解压到目标机器。
  2. 点击「下载 config.json」，把 server、enrollmentToken 填好后放到安装包目录；或直接使用下载到的配置。
  3. Windows：右键 install.bat → 以管理员身份运行；Linux：sudo ./install-linux.sh。
  4. 回到本页面刷新，客户端会出现在左侧列表。

注意：安装包里的 config.json 含注册令牌，等同于把该机器接入本 Hub 的凭据，请只发给授权设备。
