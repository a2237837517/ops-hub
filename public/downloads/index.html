安装步骤

  1. 下载对应系统的安装包，解压到目标机器。
  2. 把 config.example.json 复制为 config.json，填写 server 和 enrollmentToken（由管理员提供）。
  3. Windows：右键 install.bat → 以管理员身份运行；如果提示 A system shutdown is in progress，先重启，或运行 run.bat 前台启动（窗口不能关）。Linux：sudo ./install-linux.sh。
  4. 安装完成后，在 Ops Hub 管理页或 MCPHub 工具里刷新客户端列表。
安装包里的 config.json 含注册令牌，等同于把该机器接入 Hub 的凭据。只发给授权设备，不要公开分享。
